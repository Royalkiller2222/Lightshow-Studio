# Keyboard shortcuts

Press **?** in the app for a short list. Press **Ctrl+K** to search every
command; it shows each command's shortcut too.

## Anywhere

| Keys | Does |
| --- | --- |
| Space | Play / pause |
| Ctrl+K | Search every command |
| F1 | Open this user guide |
| ? | Shortcuts and help |
| Ctrl+Z | Undo |
| Ctrl+Y (or Ctrl+Shift+Z) | Redo |
| Ctrl+S | Save the show |
| Ctrl+O | Open a show |
| Ctrl+, | Settings: theme, start-up, updates |
| Ctrl+1 / Ctrl+2 / Ctrl+3 | Build / Program / Live workspace |
| B | Blackout on / off |
| Del | Delete the selected fixture, cue or keyframe |
| Esc | Deselect |

## 3D view

| Keys / mouse | Does |
| --- | --- |
| V | Select tool |
| X | Move tool |
| C | Rotate tool |
| Left-drag | Orbit the camera |
| Right-drag | Pan |
| Scroll | Zoom |

## Program (timeline)

| Keys / mouse | Does |
| --- | --- |
| M | Add a marker at the playhead |
| Ctrl + wheel | Zoom the timeline |
| Shift + wheel | Scroll the timeline |
| Shift while dragging | Move a cue, marker or keyframe without snapping |
| Double-click the ruler | Add a marker there |
| Double-click a track name | Rename the track |
| Double-click a keyframe | Delete it |
| Double-click a library item, or Enter | Add it at the playhead |

## Live

| Keys | Does |
| --- | --- |
| 1 – 9 | Jump to section pad 1–9 |
| ← / → | Previous / next section |
| A | Auto on / off |
| F | Fullscreen |
| Double-click a master fader | Reset it |

## Search box (Ctrl+K)

| Keys | Does |
| --- | --- |
| ↑ / ↓ | Choose a command |
| Enter | Run it |
| Esc | Close |
